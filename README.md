# THE ARCHIVE

THE ARCHIVE is Asghar Ali's engineering portfolio: a single-page portfolio with project case studies, presented in a restrained industrial visual style.

## Built with

- Next.js App Router
- React and TypeScript
- Tailwind CSS
- CSS animations and browser APIs for ambient background effects

## Features

- Single-page portfolio with section navigation and responsive menu.
- Six featured projects on the homepage and a complete project index.
- Individual project case studies with generated routes.
- CSS-based ambient lighting, architectural line animation, and restrained card hover effects.
- Reduced-motion support and touch-aware cursor lighting.

## Requirements

- Node.js compatible with the installed Next.js version.
- npm.

## Install

```bash
npm ci
```

## Local development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

No environment variables are required by the current application.

## Checks and production build

```bash
npm run lint
npm run build
npm run start
```

`npm run start` serves the production build locally after `npm run build`.

## Deployment

Deploy as a Next.js application to a compatible hosting provider, such as Vercel, or to a Node.js server configured for Next.js. Use the provider's standard Next.js build and start workflow. No environment variables need to be configured for the current application.
